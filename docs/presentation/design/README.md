# Presentation workspace

The design concept behind `../index.html`, kept so the deck can be revised.

| File | What it is |
|---|---|
| `DESIGN.md` | Design rules for every slide (one point per slide, TUM design system, no em-dashes, tables size to content). |
| `content.md` | The content gate: one row per slide with the one point, the "so what", the evidence and the status. No slide exists without an approved row here. |
| `Sprechtext-Folien.md` | Speaker text per slide (German): what is on the slide, what to say, what the audience should take away, likely questions. |
| `Laeufe-Windows-2026-10-08.md` | Protocol of the 27 Windows runs, written while they ran. |

The deck itself: `../index.html` + `../assets/` (reveal.js, open in a browser) and
`../Agentic-AI-GUI-Agent-Deck.pdf`.
